# Licensing

MiracZV applies different licenses to different kinds of material:

| Material | License | SPDX identifier |
|---|---|---|
| Firmware source code, build scripts, and configuration | Apache License 2.0 | `Apache-2.0` |
| Project documentation and explanatory written material |
Creative Commons Attribution 4.0 International | `CC-BY-4.0` |
| Hardware design files, when published |
CERN Open Hardware Licence Version 2 - Permissive | `CERN-OHL-P-2.0` |

The root [`LICENSE`](LICENSE) contains the Apache-2.0 text used for the firmware.
The other complete license texts are in [`LICENSES/`](LICENSES/):

- [`Apache-2.0.txt`](LICENSES/Apache-2.0.txt)
- [`CC-BY-4.0.txt`](LICENSES/CC-BY-4.0.txt)
- [`CERN-OHL-P-2.0.txt`](LICENSES/CERN-OHL-P-2.0.txt)

Schematic, PCB, fabrication, mechanical, and other hardware design files are
not part of this initial source release. They will be added under
CERN-OHL-P-2.0 when they are published.

An SPDX identifier in an individual file takes precedence for that file.
Third-party source and dependencies remain under their original licenses; see
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) and
[`CONTRIBUTION.md`](CONTRIBUTION.md).
